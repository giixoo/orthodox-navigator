# How to use help

| Key | What it does |
|---|---|
| **↑ ↓ PgUp PgDn Home End** | scroll |
| **Tab / Shift+Tab** | select the next / previous link |
| **Enter** | open the selected link |
| **Backspace** | back to the previous page |
| **F1** | the [contents](index.md) |
| **Esc** | close help |

The mouse wheel scrolls; a click on a link opens it.

The pages are Markdown files (`rust/help/*.md` in the source), built into the program. Links between them
are ordinary Markdown links, so they read well on GitHub too.
