# Orthodox Navigator help

A two-panel file manager in the spirit of DOS Navigator, made as a developer's pocket knife: open it from
the command line with `on`, do the job, leave.

## Keys, by where you are

- [Panels](panels.md) - moving around, working with files, selecting
- [Command line and user screen](cmdline.md) - running commands, Ctrl+O
- [Viewer](viewer.md) - F3
- [Editor](editor.md) - F4
- [Preview panel](preview.md) - Ctrl+L
- [Directory tree](tree.md) - Alt+F10
- [Drives and favourites](favorites.md) - Alt+F1 / Alt+F2
- [Remote panels: SFTP and FTP](remote.md) - in the drive list
- [Find files](find.md) - Alt+F7
- [Compare files and git](diff.md) - Shift+F3, Alt+F3
- [Batch rename](rename.md) - Alt+F6
- [User menu and file commands](usermenu.md) - F9
- [Developer tools](tools.md) - F2
- [System monitor](sysmon.md) - Alt+F5
- [Calculator](calc.md) - Ctrl+F2
- [Colour themes](themes.md) - Ctrl+T
- [Orthodox game](game.md) - Ctrl+G

## Everywhere

| Key | What it does |
|---|---|
| **Esc** | closes the window or dialog you are in |
| **F1** | help for the place you are in |
| **F10** | the menu (in the panels) |
| **Shift / Ctrl / Alt** | hold one: the key bar at the bottom shows what the F-keys do with it |

With the mouse, the `[■]` mark in the top left corner closes full-screen windows, and the key bar is
clickable.

See also [How to use help](help.md).
