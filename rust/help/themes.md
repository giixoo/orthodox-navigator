# Colour themes

**Ctrl+T** in the panels. **↑ ↓** try a theme (it shows at once), **Enter** keeps it, **Esc** goes back to
the one you had.

- **DN Gray**, **DN Blue**: DOS Navigator's own colours
- **VS Code: ...**: every theme installed in VS Code (built-in and from extensions)
- **VS Code (current theme)**: follows whatever theme VS Code uses, read each time ON starts
