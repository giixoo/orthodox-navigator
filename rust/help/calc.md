# Calculator

**Ctrl+F2** in the panels. Type an expression; the result shows at once in decimal, hex, binary, octal
and exponent form.

Numbers: `42`, `3.14`, `1e6`, `0xFF` or `$FF` (hex), `0b1010`, `0o17`. Operators: `+ - * / %` and `^`
(power), brackets.

**↑ ↓** choose which form to copy; **Copy** puts it on the command line; **Evaluate** replaces the
expression with its value so you can go on calculating. **Tab** moves between the parts, **Esc** closes.
