# Directory tree

**Alt+F10** in the panels. `[+]` marks a folder that has folders inside, `[-]` an opened one.

| Key | What it does |
|---|---|
| **↑ ↓ PgUp PgDn Home End** | move |
| **→** | open the folder in the tree `[+]` |
| **←** | close it `[-]` |
| **Enter** | go to the folder in the panel |
| **Esc** | close |

Click `[+]` / `[-]` to open or close; double click goes to the folder.
