# Preview panel

**Ctrl+L** in the panels: the other panel shows the file under the cursor (with syntax colours), or a
summary of a folder: how many files, their size, the git branch. **Ctrl+L** again turns it off.

**Tab** (or a click on it) gives it the keyboard; its title lights up. Then it has the
[viewer's](viewer.md) keys:

| Key | What it does |
|---|---|
| **↑ ↓ PgUp PgDn Home End** | scroll |
| **F2** | wrap long lines on / off (on at first: a panel is narrow) |
| **F3** | open the file in the viewer |
| **F4 / F5 / F6 / F8** | hex, JSON/XML formatting, syntax colours, code page |
| **Tab, Esc** | back to the file panel |

The mouse wheel over the preview scrolls it, even without the keyboard.
