# Editor

**F4** in the panels (**Shift+F4** for a new file). Keeps the file's encoding (UTF-8 with or without BOM,
UTF-16, Windows-1251), its line endings and its indentation.

| Key | What it does |
|---|---|
| **F2** | save |
| **Esc** | close (asks to save if changed) |
| **Shift+arrows**, mouse drag | select |
| **Ctrl+A** | select all |
| **Ctrl+C / Ctrl+X / Ctrl+V** | copy / cut / paste |
| **Ctrl+Z / Ctrl+Shift+Z** | undo / redo |
| **Ctrl+Y** | delete the line |
| **Ctrl+D** | duplicate the line |
| **Tab / Shift+Tab** | indent / unindent the selected lines |
| **F7 / Shift+F7** | search / search again |
| **Ctrl+G** | go to line |
| **F6** | syntax colours on / off |
| **Ctrl+← / Ctrl+→** | by words |
| **Ctrl+Home / Ctrl+End** | start / end of the file |
