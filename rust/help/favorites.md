# Drives and favourites

**Alt+F1** (left panel) or **Alt+F2** (right panel). Drives, the Temp panel, your favourite folders, each
with a name you choose (work, docs, downloads...), and your [remote connections](remote.md) (SFTP, FTP).

| Key | What it does |
|---|---|
| **Enter**, double click | go there |
| **letter** | that drive |
| **1 ... 9** | that favourite |
| **F7** | add the panel's folder |
| **F4** | rename / change the folder |
| **F8, Del** | remove |
| **Ctrl+↑ / Ctrl+↓** | move a favourite up / down |
| **Ins** | in the Remote part: a new connection (F4 edits it, F8 deletes it) |
| **Esc** | close |

**Ctrl+D** in the panels adds the current folder without opening the list.
